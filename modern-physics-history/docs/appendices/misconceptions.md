# 附录B. 十六个常见误解，以及更准确的说法

| 容易产生的印象 | 更准确的理解 | 正文与出处 |
|---|---|---|
| 1900年前物理已经基本完工 | 热辐射、原子、不可逆性、电动力学与运动等问题并未统一解决 | [§1.1](../chapters/01-thermal-legacy.md#q-1-1)、[§1.2](../chapters/01-thermal-legacy.md#q-1-2)、[§2.1](../chapters/02-quantum-birth.md#q-2-1)、[§3.1](../chapters/03-relativity.md#q-3-1) |
| 普朗克在1900年已经具有成熟的光子观 | 能量元、光量子与成熟量子场论之间经历了长期概念发展 | [§2.1](../chapters/02-quantum-birth.md#q-2-1) |
| 相对论完全由迈克耳孙—莫雷实验直接推出 | 它来自更广泛的电动力学与时空问题，不能压缩成单一实验因果 | [§3.1](../chapters/03-relativity.md#q-3-1) |
| 不确定性只因为仪器把粒子撞歪 | 非对易可观测量及量子态结构是更基础的层次 | [§2.4](../chapters/02-quantum-birth.md#q-2-4)、[§2.6](../chapters/02-quantum-birth.md#q-2-6) |
| 量子场论只研究很小的粒子 | 它也组织多体激发、临界现象和低能有效自由度 | [§4.1](../chapters/04-quantum-fields.md#q-4-1) |
| 对称性一定全部成立 | 宇称、CP等必须逐类相互作用检验，且要区分显式与自发破缺 | [§6.2](../chapters/06-particles.md#q-6-2)、[§6.3](../chapters/06-particles.md#q-6-3) |
| Higgs解释了普通物质的全部质量 | 核子的大部分质量与强相互作用动力学有关，耦合参数也仍需测量 | [§6.4](../chapters/06-particles.md#q-6-4) |
| 知道基本粒子以后凝聚态只剩应用 | 集体态、普适性、分数化和拓扑需要新的概念与方法 | [§7.2](../chapters/07-condensed-matter.md#q-7-2)、[§8.4](../chapters/08-criticality.md#q-8-4) |
| 二维连续系统没有通常有序，就完全没有相变 | 适当条件下可以有BKT类转变与准长程有序 | [§9.2](../chapters/09-topological-matter.md#q-9-2) |
| KPZ就是任何随机生长或任何随机PDE | 方程、普适类和一般生长现象是不同范围 | [§11.5](../chapters/11-nonequilibrium.md#q-11-5)、[§11.6](../chapters/11-nonequilibrium.md#q-11-6) |
| 混沌就是没有规律 | 确定性方程可以有有限预测时域，同时仍有可研究的统计结构 | [§10.1](../chapters/10-nonlinear-dynamics.md#q-10-1) |
| 生命局部有序，所以违反第二定律 | 生命是开放耗能系统，需要核算环境与系统的整体熵变化 | [§11.3](../chapters/11-nonequilibrium.md#q-11-3)、[§12.4](../chapters/12-soft-active-living-matter.md#q-12-4) |
| 一个漂亮的黑洞解就等于它真实可形成且稳定 | 形成、稳定、观测和精确解是不同问题 | [§3.4](../chapters/03-relativity.md#q-3-4) |
| 暗物质已被明确识别为某一种粒子 | 多类引力证据强，但具体微观身份仍是研究目标 | [§17.4](../chapters/17-cosmology.md#q-17-4) |
| AdS/CFT已经证明现实宇宙就是二维投影 | 它是特定理论间的深刻对偶框架，有明确适用对象与待解问题 | [§18.4](../chapters/18-black-holes.md#q-18-4) |
| 获奖年份就是发现年份，获奖名单就是完整贡献名单 | 二者常常不同；例如1980年代电路实验在2025年获奖，大型合作更不能只写少数人 | [§15.5](../chapters/15-quantum-information.md#q-15-5)、[§19.6](../chapters/19-methods.md#q-19-6) |
