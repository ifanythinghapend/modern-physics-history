# 项目纲领

本项目以具体问题串联现代物理的发展：问题怎样出现，已有解释为什么不足，哪些研究者、实验和方法改变了认识，这些成果今天仍在回答什么问题。阅读者应能沿正文理解学科关心什么，也能沿出处复查一项说法。

本文规定编写与协作方式。[编审大纲](../docs/outline.md)说明全书的叙述安排，[审阅指南](REVIEW_GUIDE.md)说明怎样核证，[贡献说明](../CONTRIBUTING.md)说明修改入口。项目保持公开讨论稿定位；构建成功不表示全书已经完成学术审阅。

## 一、范围与写法

历史叙述从十九世纪的场、热与概率出发，重点讨论二十世纪以来的理论、实验和分支发展。各章按问题组织，在章内保留必要的年代关系；时间轴提供跨章对照。各分支不按正文的排列顺序依次产生。

每一段重要叙述要能回答：当时有什么困难，研究者实际完成了什么，成果依赖什么条件，又留下什么问题。姓名和年代服务于这条线索。团队、仪器、测量与理论工作分别写清，避免用获奖者名单代替发展史。

今天的问题可以帮助选择材料，但不得把后来形成的概念、证据或目标归给早期研究者。历史上的论证与使用现代语言整理的推导分开说明；仍有争论的归属和解释保留其证据差异。

新增内容须说明与现有小节的关系。足以补成一段的材料不单独开章；需要新章时先修改编审大纲中的问题主线，再登记结构。

## 二、正确性与出处

重要史实、贡献归属、关键数量、实验结论和时效性判断须有可定位的来源；数学结论也可由条件明确的完整推导支持。引用放在相关论断附近，不用一串参考链接概括支持整个章节。

来源按所核问题选择。原论文用于确认作者写了什么，专业史学研究用于考察语境与优先权，教材或综述用于现代解释，实验论文用于核对装置、数据与结论范围。新闻及机构介绍可提供线索，不能自动代替上述证据。原始材料也应核对版本、译文和适用范围。

文献可访问、书目信息准确、来源确实支持该句、论证在条件内成立，是不同的检查。自动程序检查文件、编号、链接、公式格式与生成物一致性；内容审阅负责证据解释和推理，不把二者混称为“已验证”。

对发现优先权、解释争议、近似条件及开放问题优先保留核对记录。已有文献数量不是完成标准，补证应对应具体缺口。

## 三、推导与阅读

推导单独维护，在阅读版中按章节标记放回原位置。直接推动问题解释的短推导连续呈现；长篇技术展开可给出关键步骤和结论后链接全文。现有短推导不因文件独立而从正文移走。

推导交代计算对象、记号、模型假设、边界条件、近似、关键步骤及失效情形。模型的选择、能量基准的约定与近似舍项分别说明；检查量纲、符号和可用的极限。现代重构明确说明与历史论证的关系。

正文优先用完整句子区分模型内结论、实验支持、历史解释和开放问题。只有容易混淆的地方加提示，不逐句堆叠标签。

## 四、编辑源与发布物

每类信息只有一个权威编辑入口：

| 信息 | 编辑源 | 由此生成或排版的内容 |
| --- | --- | --- |
| 篇章顺序、标题、推导归属、版本文字 | `data/book.json` | 导航、篇章顺序与推导目录 |
| 叙述与推导 | `docs/preface.md`、`docs/chapters/`、`docs/derivations/` 中的编号文件 | 合并稿、网页、PDF |
| 文献登记 | `docs/appendices/references.md` | `data/references.json`、简式 BibTeX |
| 时间轴 | `docs/appendices/timeline.md` | `data/timeline.json` |
| 核心问题的出处对应 | 正文引用及 `docs/appendices/question-index.md` | `data/questions.json` |
| 编审理由与核对过程 | `docs/outline.md`、`handbook/reviews/` | 供协作者查阅，不另设手工目录或全书认证表 |

`manuscript.md`、`index.html`、索引 JSON、BibTeX 和推导目录均是生成物。当前 BibTeX 保存资料短标签、网址与类型，不宣称是完整学术书目库。新增结构化书目工具时，必须同时迁移读取程序、贡献说明和旧编号映射，不能出现两套同时编辑的书目。

同一发布版本的网页、Markdown 与 PDF 使用同一套文献身份和编号。保留既有章节、问题和文献锚点。PDF 须注明其对应版本；内容变化后的发布应重建阅读文件，或明确标出尚未同步的快照。

现行发布采用仓库根目录的静态网页和 GitHub Pages 分支发布。工具变更以具体阅读或维护问题为依据，先验证中文、公式、原有链接、离线阅读及 PDF，再决定是否替换。内容审阅不以迁移框架为前提。

## 五、协作与审阅状态

协作分为作者自查、交叉审阅、维护者合并。角色可以兼任，修订错字和补链接无需完整学术审阅流程。涉及核心公式、发现归属或实验解释的修改，合并前应说明核对证据；没有作者之外的合适审阅者时，明确保留待交叉审阅状态。

状态使用“待核对”“核对中”“本版本已审阅”，并写明书目、历史、物理、数学或行文等范围，以及对应提交或源文件摘要。某个小节的核对不能提升为整章、整书的认证。实质修改后复核受影响的论断和后续推论；只有文字调整时说明不影响原结论的理由。

争议通过具体原句、材料和推理讨论。证据不足时缩小断言、并列解释或标记待核，不用程序通过或多数意见代替论证。

## 六、公开材料

公开文件仅包含项目内容和经授权公开的信息，不收录私人联系方式、聊天记录、本地路径或访问凭据。核对记录不要求真实姓名，可使用经本人同意的公开贡献标识。
