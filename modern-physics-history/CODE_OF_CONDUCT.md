# 协作约定

这个项目依靠可查证的资料和具体讨论改进。参与 Issue、Pull request 或文稿修改时，请遵守以下约定：

- 针对文字、推导、资料和论证提出意见，避免人身评价、歧视和骚扰。
- 区分已确认的错误、解释分歧和仍需查证的问题；能提供出处时尽量提供。
- 尊重贡献者的劳动。引用和转述应交代来源，不提交无权公开的材料。
- 不披露参与者未同意公开的真实姓名、联系方式或私人对话。
- 不以刷屏、重复争论或无关推广妨碍讨论。

普通内容分歧可在相应 Issue 中讨论。涉及隐私或骚扰的情况，不要为举证在公开区再次传播相关信息，可使用 GitHub 的举报渠道。维护者可要求修改或删除不合适的内容，关闭失去讨论基础的线程，并按平台规则限制持续违规的参与。

处理意见应说明涉及的行为和依据。不同学术观点本身不是处分理由。
